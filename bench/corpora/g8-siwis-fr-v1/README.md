# Voix française G8

Écouter les deux phrases réservées sur [la facture](reserve-facture.wav) et [le trajet en RER](reserve-retour.wav). Les neuf éléments attendus sont présents dans la transcription indépendante. Le contrôle initial a compté « 35 € » comme un échec pour « 35 euros ». Le relevé conserve ce premier score et la correction sur les mêmes WAV. Les seuils de temps, de mémoire et d’arrêt figurent dans le [protocole figé](reserve.json). Pour rejouer le lot, lancer `python -m bench.verify_g8_voice --holdout`. [Résultat](../../results/g8-siwis-fr-reserve-v1.json)

Les trois phrases françaises de ce répertoire ont été écrites pour le banc Akasha. Les WAV sont prononcés sur CPU par Piper, avec la voix SIWIS medium à 22 050 Hz. Le fichier `phrases.json` donne le texte affiché et les termes à reconnaître, dont un nom propre, une date, une heure, un montant et deux sigles.

Le moteur Windows est la version 2023.11.14-2 de Piper (MIT), distribuée avec eSpeak NG (GPL). La fiche de cette révision de la voix indique un entraînement sur le corpus français SIWIS (CC BY 4.0) et une initialisation à partir de la voix anglaise Lessac. Le banc conserve les extraits générés. Le moteur, les poids et leur configuration sont téléchargés séparément dans le cache personnel. [Moteur](https://github.com/rhasspy/piper/releases/tag/2023.11.14-2) · [Fiche de la révision évaluée](https://huggingface.co/rhasspy/piper-voices/blob/375a0fe641dea077c2a47b4e9a056d6da521eed3/fr/fr_FR/siwis/medium/MODEL_CARD) · [Corpus SIWIS, Université d’Édimbourg](https://datashare.ed.ac.uk/handle/10283/2353)

Le premier essai utilise la vitesse par défaut. Le second espace les lettres de sigles usuels et règle la durée relative à 1,1. Les deux essais envoient chaque WAV à whisper.cpp small français sur CPU. La vérification accepte les nombres en lettres ou en chiffres et la notation horaire compacte. Le premier relevé brut comptait « 14h » comme un échec malgré une heure correctement restituée. Le taux de reconnaissance porte sur ces trois réponses synthétiques. L’utilisateur peut écouter les WAV pour juger la voix.

Depuis la racine du dépôt, `python -m bench.verify_g8_voice` régénère le lot avec les caches préparés. `python -m bench.verify_g8_desktop` actionne les boutons de lecture et d’arrêt avec une sortie audio Windows disponible.
